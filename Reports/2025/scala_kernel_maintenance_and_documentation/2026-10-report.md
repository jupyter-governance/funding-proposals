## Summary of Work Completed

During this period, Almond [0.15.0](https://github.com/almond-sh/almond/releases/tag/v0.15.0) was released, many GitHub issues
were triaged, Almond's implementation of the Jupyter protocol was reviewed and fixed, security hardening work was done (with
fixes contributed to upstream projects too), rework of the documentation started, and Jupyter widgets support was added (to be released).

### Releases

Almond [0.15.0](https://github.com/almond-sh/almond/releases/tag/v0.15.0) was cut on at the end of September.

To lower the number of modules published at each release, helper modules that change at a slower pace were moved to their own repositories, where they can be released on their own (https://github.com/almond-sh/almond/pull/1792, https://github.com/almond-sh/almond-scalapy/pull/1, https://github.com/almond-sh/almond-jackson/pull/1). All releases are also published to GitHub Packages as a backup (https://github.com/almond-sh/almond/pull/1771).

[almond-scalafmt](https://github.com/almond-sh/almond-scalafmt), a Jupyterlab extension that can format Scala code, was updated to JupyterLab 4 (https://github.com/almond-sh/almond-scalafmt/pull/18) and [released](https://github.com/almond-sh/almond-scalafmt/releases/tag/v0.2.0). Related changes in Almond were merged (https://github.com/almond-sh/almond/pull/1793).

### Security

I looked into Almond's security with the help of LLMs (mainly Opus 5.5), which allowed to fix a number of security-related issues:

- https://github.com/almond-sh/almond/pull/1825: more careful handling of HMAC signatures
- https://github.com/almond-sh/almond/pull/1828: various ZeroMQ message handling fixes
- https://github.com/almond-sh/almond/pull/1837: limit ZeroMQ message sizes by default
- https://github.com/almond-sh/almond/pull/1829: sanitize HTML display output
- https://github.com/almond-sh/almond/pull/1832: tests for unsafe schemes in FileLink URLs
- https://github.com/almond-sh/almond/pull/1833: protect kernel secrets during installation
- https://github.com/almond-sh/almond/pull/1834: prevent force installs from following symlinks
- https://github.com/almond-sh/almond/pull/1830: pin Docker images and verify Coursier downloads in Docker builds
- https://github.com/almond-sh/almond/pull/1835: remove the JitPack repository dependency

Extra security-related work:

- https://github.com/almond-sh/almond/pull/1854: add threat model and [OSS Scanner](https://github.com/anthropics/oss-scanner) image
- https://github.com/almond-sh/almond/pull/1864: add security policy (`SECURITY.md`)
- https://github.com/anthropics/oss-scanner/pull/1204: enroll Almond in OSS Scanner (awaiting review)

This resulted in contributions to other projects too:

- in [JeroMQ](https://github.com/zeromq/jeromq), the ZeroMQ implementation used by Almond: messages with a very large announced size made it allocate very large buffers upfront, before signature checking. Initial allocation can now be limited (https://github.com/zeromq/jeromq/pull/1023).
- in [xeus-zmq](https://github.com/jupyter-xeus/xeus-zmq): while comparing Almond with other kernels, the model found that malformed messages sent to the IOPub socket of xeus kernels could terminate their process. Those messages are now ignored (https://github.com/jupyter-xeus/xeus-zmq/pull/92).
